## Task 1: Chevy Hangman Game

A simple text-based Hangman game called Chevy Handman game.

Features
- Randomly selects a word from a list of 5 predefined words
- Player guesses one letter at a time
- Maximum of 6 incorrect guesses allowed
- Displays the current state of the word and previously guessed letters

## Task 2 :  Simple Chat box Rule

A simple rule-based chatbot that responds to basic messages.
Features
Responds to greetings like "hello", "hi", "hey"
Answers "how are you"
Says goodbye when the user types "bye"
Continues chatting until the user types "quit"y
